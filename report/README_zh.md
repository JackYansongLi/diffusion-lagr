# 一小时内交付的复现审计报告

[阅读 PDF](report.pdf) · [LaTeX 源文件](report.tex) · [完整运行说明](../repro/README.md)

这份报告是**真实 demo 数据的统计与数值验证、解析日程重算和复现可行性审计**，不是“论文全部图已复现”。本阶段没有训练模型、运行检查点采样、下载完整数据或安装新软件。

已完成：

- 创建并验证 fork，固定上游提交，在独立研究分支工作。
- 列出主文图 1–6、补充图 S1–S2 的每个面板、依赖及缺失资产。
- 19 项数值测试；对仓库中 256 条真实 DNS 轨迹完成归一化验证、结构函数、广义/混合平坦度及单时刻统计。
- 2,000 次整轨迹 bootstrap：同时保留一条轨迹的所有时刻和三个分量，明确这种区间仅针对当前 DNS 子集。
- 核实加速度的单位/边界处理：按采样编号求导与按物理时间求导的二阶矩差约 197,531 倍。
- 解析重算图 3b 的噪声日程，并并列显示论文与代码的线性日程差异。
- 实测有限样本敏感性：最小滞后下，前三条轨迹贡献约 79% 的八阶矩；删掉单条轨迹最多改变约 37%。
- 提供按批次写盘、保存指定中间状态的独立采样入口；其规划逻辑已测试，神经网络执行路径尚未运行。

后续需要的完整 DNS3c 与两份作者生成样本约 27.2 GB，解包还需额外磁盘。1%/10% 模型、早期检查点、训练日志与 WGAN 资产仍缺失。报告包含逐图状态表，未完成项不会用合成代理或原论文截图替代。

从仓库根目录运行 `python -m repro.report_tables`，再进入 `report/` 执行 `latexmk -pdf -interaction=nonstopmode -halt-on-error report.tex` 可重建 PDF。报告中数值表格由测量 JSON 自动生成；完整种子、命令、哈希、原始统计量和结果摘要均在 `repro/`。
